# Integração C com Impressora Elgin i9

# 📘

# Sobre o Projeto

# Este projeto foi desenvolvido em linguagem C com o objetivo de integrar uma aplicação à impressora 

# Elgin i9, utilizando a DLL disponibilizada pela fabricante. A aplicação permite realizar diferentes 

# operações de impressão e comunicação com a impressora por meio de um menu interativo.

# O trabalho faz parte da disciplina de Programação Orientada a Objetos.

# 🧰

# Tecnologias Utilizadas

# Linguagem C

# Dev-C++ (ambiente de desenvolvimento)

# DLL 64 bits

# Windows API

# Comandos de impressão da biblioteca Elgin

# ⚙

# Funcionalidades

# Configuração e abertura de conexão com a impressora.

# Impressão de textos.

# Impressão de QR Codes.

# Impressão de códigos de barras.

# Impressão de XML SAT.

# Impressão de XML de cancelamento SAT.

# Abertura de gaveta.

# Emissão de sinal sonoro.

# Controle de conexão com a impressora.

# Sistema de login com limite de tentativas.

# Instalação e Execução

# 1\. Baixe ou clone o repositório.

# 2\. Configure o ambiente de desenvolvimento.

# 3\. Disponibilize a DLL da Elgin na pasta de execução do programa.

# 4\. Coloque os arquivos XML necessários na mesma pasta.

# 5\. Compile o código-fonte.

# 6\. Execute o programa.

# 7\. Configure a conexão com a impressora e escolha a operação desejada no 

# menu.
